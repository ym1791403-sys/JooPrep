## 🛠️ المعمارية والوحدات الأساسية

### 1. كويزات الخطوات الوسيطة (Deterministic Math Engine)
* **محرك حسابي حتمي 100% (No AI Hallucination):** الحسابات الرياضية تُحسب بالكود بدقة مطلقة دون الاعتماد على الذكاء الاصطناعي لتفادي أخطاء الحسابات الطويلة.
* **Problem Generator:** توليد مسائل عشوائية محكومة (محددات 3x3 محددها غير صفري، معكوس المصفوفات 2x2 و 3x3، أنظمة العد، متمم الاثنين، وحساب قدرة الدوائر).
* **Answer Normalizer:** يتقبل جميع صيغ الإدخال (كسور مثل `1/2` أو `0.5`، أرقام سالبة، فراغات، ومصفوفات).
* **Error Classifier (مصنف الأخطاء):** تشخيص أخطاء الطلاب المتكررة:
  - خطأ إشارة (`الرقم صح والإشارة غلط، راجع شبكة الإشارات`).
  - نسيان القسمة على المحدد (`ناقصك تقسم على det(A)`).
  - نسيان التدوير (`المرافقات محتاجة تبديل الصفوف بالأعمدة Transpose`).
  - قراءة البواقي بالعكس (`اقرا البواقي من تحت لفوق`).
  - إشارات القدرة في الدوائر الكهربية (`القدرة الممتصة موجبة لو التيار داخل من الطرف الموجب`).
* **Hint Ladder (سلم التلميحات):** 3 مستويات تلميح تدريجية لكل خطوة قبل الكشف عن الحل.
* **أوضاع التشغيل:** وضع التدريب الفوري، ووضع الامتحان المؤقت.

### 2. محاكي المناقشة الشفوية (Oral Viva Defense Simulator)
* **شخصيات الممتحنين الأربعة:**
  - 👨‍🏫 **المعيد الصارم (Strict TA):** يركز على Syntax، Edge Cases، الذاكرة، و Pointers.
  - 🎓 **الأستاذ الأكاديمي (Academic Prof):** يركز على Big-O، هياكل البيانات، والبدائل التصميمية.
  - 🤝 **المعيد الودود (Friendly TA):** تدريب هادئ وتلميحات مشجعة.
  - ⚡ **الدكتور المفاجئ (Surprise Doc):** أسئلة ضغط واقعية وتحديات "ماذا لو؟".
* **خريطة المشروع (Project Map):** عزل كود الطالب واستخلاص الدوال، الخوارزميات، ونقاط الخطر (Pointers, Memory leaks, Recursion) بأمان كامل من Prompt Injection.
* **معايير التقييم الرسمية (Rubric):**
  - 40% صحة المعلومة
  - 30% العمق والتبرير
  - 20% وضوح الشرح
  - 10% التعامل مع أسئلة ماذا لو
* **التقرير الختامي للمناقشة:** تقييم شامل، 3 نقاط قوة، 3 نقاط ضعف حاسمة، ومواضيع موصى بها للمراجعة، مع إمكانية التصدير والطباعة كـ PDF.

### 3. ورقة التحضير الذكية (Smart Prep Sheet)
* توليد 10 أسئلة فخ متوقعة على كود المشروع مع توضيح سبب الفخ وإجابة نموذجية مختصرة مبهرة.
* جاهزة للطباعة والتصدير PDF للمراجعة قبل دخول المعمل.

### 4. مؤشر الجاهزية والخريطة الحرارية (Readiness Index R)
* حساب رياضي ديناميكي:
  $$R = 0.5 \cdot Q + 0.5 \cdot V$$
  حيث $Q$ تمثل دقة الكويزات بوزن تصاعدي لآخر 5 محاولات، و $V$ تمثل متوسط درجات آخر 3 جلسات شفوي.
* خريطة حرارية لمستويات المواضيع.
* توصية **"ذاكر ده الأول"** لأضعف 3 مواضيع عند الطالب.

### 5. دفتر الأخطاء (Error Notebook)
* تجميع المسائل التي أخطأ فيها الطالب حسب نوع الخطأ مع زر لإعادة حلها فورياً.

## 🎨 تجربة المستخدم والتصميم (UI / UX)
- **Mobile-First بالكامل:** الوصول لأول سؤال في أقل من 3 ضغطات.
- **واجهة RTL أنيقة:** خط Cairo العربي الحديث، مع احتفاظ الكود والمعادلات الرياضية باتجاه LTR السليم.
- **لوحة مفاتيح رياضية ومحرر مصفوفات:** كتابة الأرقام والكسور والمصفوفات بضغطة زر دون عناء كتابة الأقواس على الهاتف.
- **دعم الوضع الداكن والفاتح (Dark / Light Mode)**.
- **صوت وقراءة ناطقة آلية:** باستخدام Web Speech API مع خيار الكتم/التشغيل بنقرة واحدة.
